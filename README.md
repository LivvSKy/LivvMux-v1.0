# LivvMux v2.2

LivvMux adalah AI Terminal untuk Termux berbasis Gemini API.
Ringan, UI hijau-hitam, dan user-friendly.

## Fitur
- Input API key langsung dari terminal
- Prompt AI custom (user)
- UI Rich modern
- Command system
- Cocok HP low-end

## Install
```bash
git clone https://github.com/username/LivvMux
cd LivvMux
chmod +x install.sh
./install.sh
./run.sh
