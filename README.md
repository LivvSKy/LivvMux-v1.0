# LivvMux v2.2

LivvMux adalah AI Terminal untuk Termux berbasis Gemini API.
Ringan, UI hijau-hitam, dan user-friendly.

## Fitur
- Input API key langsung dari terminal
- Prompt AI custom (user)
- UI Rich modern
- Command system
- Cocok HP low-end

## Install
```bash
pkg update && pkg upgrade
pkg install git python -y

git clone https://github.com/LivvSKy/LivvMux-v1.0.git
cd LivvMux-v1.0

chmod +x install.sh
./install.sh
./run.sh
